## verify-2 명세 확인 4건 — 사람 결정 (2026-11-11)

1. **계약 범위와 원리금균등 지원 범위의 차이** → 유지. 현재 상품(최대 60개월)에는 영향이 없다. 장기 상품을 열 때 잔여 회차 재산정 방식으로 재설계한다(생성기 Javadoc·전체 가이드 13-5).
2. **소수부가 0인 원금의 스케일이 결과에 남음** → 보류. 실제 실행 경로에서도 원금은 DB `DECIMAL(19,4)`에서 읽어 같은 칸에 다시 저장하므로 값·표시 차이가 없다.
3. **월이율이 0으로 반올림되는 극소 양수 연이율** → 조치 안 함. 현실에 없는 입력이고 SCH-08 허용폭 안이다.
4. **reject 판정이 거부 사유를 구분하지 않음** → 반영(`341e41e`). 계약 밖이면 어떤 `IllegalArgumentException`이든, 계약 안이면 '잔액 음수'만 인정한다. CSV 열을 늘리지 않고 판정만 강화했다.
